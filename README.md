# KCORC Summer School

This repository contains materials, examples, and resources for the KCORC Summer School program.

## Overview

The KCORC Summer School repo is designed to store lecture notes, sample code, datasets, and project templates for participants.

## Contents

- `README.md` - repository overview and usage instructions
- `ORC_turbo_design/` - lessons and exercises related to ORC turbo design
- `tespy/` - lessons and exercises related to the TESPy modeling workshop
- `pyproject.toml` - configuration file for Python project dependencies


## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-org>/KCORC_summer_school.git
   ```

2. Review the available materials in the `docs/`, `examples/`, and `projects/` folders.

3. Follow any instructions in the lesson-specific documentation.

## Contribution

- Add new lesson materials under `docs/`.
- Place code examples and notebooks in `examples/`.
- Add data files necessary for exercises in `data/`.
- Keep the repository organized and document changes clearly.
